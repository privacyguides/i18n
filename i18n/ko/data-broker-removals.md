데이터 브로커가 운영하는 "인물 검색 사이트"는 대다수 미국인에게 막대한 프라이버시 위험이 됩니다. 많은 사람의 주소, 전화번호, 이메일, 나이 같은 민감한 개인 정보를 간단한 인터넷 검색만으로 찾을 수 있습니다. 안타깝게도 여러분의 데이터를 보호하는 연방 규정은 없지만, 이러한 회사 중 상당수는 요청하면 _공개_ 데이터베이스에서 여러분의 정보를 삭제해 줍니다.

:flag_us: **참고:** 이 도구 중 상당수는 미국에서만 사용할 수 있으며, 데이터 브로커가 공공 기록과 기타 자료에서 정보를 수집, 공유, 판매하는 것은 주로 미국에 국한된 문제입니다. 다른 많은 지역에서는 GDPR 같은 규정을 통해 이미 데이터가 보호되고 있습니다. 프라이버시 가이드는 미국에서도 이와 비슷하게 강력한 프라이버시 보호가 마련되도록 항상 지지하겠지만, 현재 피해를 입고 있는 사람들은 이러한 "임시방편" 솔루션으로도 도움을 받을 수 있습니다.

역설적이게도 이러한 사이트에서 인터넷에 공개된 개인 데이터를 삭제하려면, 대개 요청을 처리할 수 있도록 해당 회사에 개인 데이터를 _제&#xACF5;_&#xD574;야 합니다. 안타깝지만 대부분의 경우 공개적으로 접근 가능한 개인 데이터의 양을 최소화하기 위해 여전히 그렇게 할 가치가 있습니다.

<div class="admonition example" markdown>
<p class="admonition-title">직접 해 보세요</p>

자주 사용하는 [검색 엔진](search-engines.md)에서 따옴표로 묶은 이름과 대략적인 거주 지역을 함께 검색하여 데이터가 쉽게 노출되어 있는지 확인해 보세요. 예를 들어 `"Jane Smith" Chicago IL`처럼 검색해 보세요. 많은 경우 검색 결과 상위 항목의 상당수가 여러분의 개인 정보로 채워져 있을 수 있습니다. 여러분에 관한 결과가 바로 보이지 않더라도 여전히 영향을 받고 있을 수 있습니다. 아래에 링크된 데이터 브로커 목록에서 여러분의 데이터가 공개 데이터베이스에 있는지 확인할 수 있는 곳을 더 찾을 수 있습니다.

</div>

## 수동 옵트아웃 <small>무료</small> { #manual-opt-outs-free }

인물 검색 사이트에서 자신의 정보를 삭제하는 가장 빠르고 효과적이며 프라이버시를 지키는 방법은 각 사이트에 직접 옵트아웃 요청을 제출하는 것입니다. 인물 검색 사이트가 수백 개나 되기 때문에 벅찬 작업처럼 _보일_ 수 있지만, 실제로는 이러한 사이트의 대다수를 소수의 회사가 운영하고 있습니다.

먼저 이 사이트들에서 여러분의 정보를 검색하고, 정보가 발견되면 옵트아웃 요청을 제출해야 합니다. 이러한 제공업체에서 데이터를 삭제하면 대개 여러 소규모 사이트에서도 동시에 데이터가 삭제됩니다.

- Advanced Background Checks([검색](https://advancedbackgroundchecks.com), [옵트아웃](https://www.advancedbackgroundchecks.com/opt-out))
- BeenVerified([검색](https://beenverified.com/app/optout/search), [옵트아웃](https://beenverified.com/app/optout/address-search))
- CheckPeople([검색](https://checkpeople.com/do-not-sell-info) 후 _Remove Recor&#x64;_&#xB97C; 선택하여 옵트아웃)
- ClustrMaps([검색](https://clustrmaps.com), [옵트아웃](https://clustrmaps.com/bl/opt-out))
- InfoTracer([검색](https://infotracer.com), [옵트아웃](https://infotracer.com/optout))
- Intelius([검색](https://intelius.com), [옵트아웃](https://suppression.peopleconnect.us/login))
- PublicDataUSA([검색](https://publicdatausa.com), [옵트아웃](https://publicdatausa.com/remove.php))
- Spokeo([검색](https://spokeo.com/search), [옵트아웃](https://spokeo.com/optout))
- That's Them([검색](https://thatsthem.com), [옵트아웃](https://thatsthem.com/optout))
- USPhonebook([검색 및 옵트아웃](https://usphonebook.com/opt-out))
- Whitepages([검색](https://whitepages.com), [옵트아웃](https://whitepages.com/suppression_requests))

<div class="admonition tip" markdown>
<p class="admonition-title">옵트아웃 전략에 관한 팁</p>

이 과정에서 지치거나 압도당하지 않도록 주의하세요. 당장 위험에 처한 상황이 아니라면, 쉬엄쉬엄 진행하고 한꺼번에 모두 처리하지 않아도 됩니다.[^1]

한 가지 전략은 위 목록의 맨 위부터 시작하여 매주 웹사이트를 하나씩 살펴보는 것입니다. 다음 주에는 목록의 다음 웹사이트로 넘어가는 식으로 계속 진행합니다. 목록 끝에 도달하면 처음부터 다시 시작하면 됩니다.

이렇게 하면 약 3~4개월마다 각 웹사이트를 다시 검토하는 좋은 일정이 만들어지고, 전체 과정을 매주 일과에 쉽게 추가할 수 있는 5분짜리 간단한 작업으로 나눌 수 있습니다.

</div>

이 사이트들 모두에서 처음으로 옵트아웃을 완료했다면, 요청이 해당 업체의 모든 사이트에 반영될 수 있도록 1~2주 정도 기다리는 것이 좋습니다. 그런 다음 남아 있는 사이트를 검색하여 옵트아웃을 진행하면 됩니다. [구글의 _나에 관한 결과_](#google-results-about-you-free) 같은 웹 크롤러를 사용하면 인터넷에 남아 있는 데이터를 찾는 데 도움이 될 수 있습니다.

그 밖에 프라이버시 전문 기자인 야엘 그라우어가 각 사이트의 검색 도구와 옵트아웃 페이지로 바로 연결되는 링크를 포함한 훌륭한 데이터 브로커 사이트 목록을 정리해 두었습니다. 시간을 들여 각 사이트를 살펴보고, 여러분의 정보가 있는지 확인한 뒤 삭제할 수 있습니다:

[:simple-github: Big Ass Data Broker Opt-Out List](https://github.com/yaelwrites/Big-Ass-Data-Broker-Opt-Out-List){ .md-button }

자동 스캐너를 사용해 여러분에 관한 결과를 찾지 않는다면, 위험 수준과 공개된 개인 데이터의 양에 따라 3개월, 6개월 또는 12개월마다 이 과정을 다시 하도록 알림을 설정하는 것을 고려해 보세요. 안타깝게도 옵트아웃한 후에도 시간이 지나면서 데이터가 다시 나타나거나 새로운 인물 검색 사이트에 등장하는 일은 흔합니다.

## EasyOptOuts <small>유료</small> { #easyoptouts-paid }

<div class="admonition recommendation" markdown>

![EasyOptOuts 로고](assets/img/data-broker-removals/easyoptouts.svg){ align=right }

**EasyOptOuts**는 연 20달러로 여러 데이터 브로커 사이트를 검색하고 여러분을 대신해 자동으로 옵트아웃 요청을 제출해 주는 서비스입니다. 첫 검색과 삭제 과정을 즉시 수행한 다음, 시간이 지나면서 새로운 사이트에 데이터가 나타날 경우에 대비해 4개월마다 이 과정을 다시 실행합니다.

[:octicons-home-16: 홈페이지](https://easyoptouts.com){ .md-button .md-button--primary }
[:octicons-eye-16:](https://easyoptouts.com/privacy){ .card-link title="개인정보 처리방침" }

</div>

EasyOptOuts가 지원하는 일부 웹사이트는 공개적으로 검색할 수 있습니다. 이 경우 EasyOptOuts는 검색을 수행하여 여러분의 개인 데이터가 이미 발견된 경우에만 옵트아웃 요청을 제출하므로, 원래 데이터를 가지고 있지 않던 사이트에 옵트아웃 요청을 통해 데이터를 보내는 일을 막습니다. 하지만 공개적으로 검색할 수 없는 일부 사이트도 지원하는데, 이 경우에는 여러분이 해당 사이트의 비공개 데이터베이스에 있을 경우에 대비해 어쨌든 옵트아웃 요청에 데이터가 담겨 전송됩니다.

프라이버시 가이드의 [테스트](https://www.privacyguides.org/articles/2025/02/03/easyoptouts-review)에 따르면 EasyOptOuts는 매우 저렴한 가격과 높은 효과로, 지금까지 테스트한 데이터 삭제 서비스 중 가장 뛰어난 가치를 제공합니다. [컨슈머 리포트의 독립적인 조사 결과](https://discuss.privacyguides.net/t/consumer-reports-evaluating-people-search-site-removal-services/19948)에서도 EasyOptOuts는 가장 성능이 뛰어난 데이터 삭제 서비스 중 하나로 나타났습니다.

<div class="admonition failure" markdown>
<p class="admonition-title">EasyOptOuts가 지원하지 않는 우선순위가 높은 사이트</p>

EasyOptOuts는 프라이버시 가이드가 "우선순위가 높다"고 보는 다음 사이트를 지원하지 않으므로, 여전히 직접 옵트아웃해야 합니다:

- Intelius([검색](https://intelius.com), [옵트아웃](https://suppression.peopleconnect.us/login))

</div>

## 구글 _나에 관한 결과_ <small>무료</small> { #google-results-about-you-free }

<div class="admonition warning" markdown>
<p class="admonition-title">구글 자체도 데이터 수집업체입니다</p>

이 방법을 사용하려면 구글이 검색 결과를 주기적으로 모니터링할 수 있도록 개인 정보를 구글에 제출해야 합니다. 구글은 이 도구에 제공된 정보를 다른 구글 제품 전반에서 "경험을 맞춤화"하는 데 사용하지 않는다고 주장합니다.

구글은 데이터를 외부에 판매하거나 공유하지 않으므로 엄밀히 말해 데이터 브로커는 _아니지만_, 일부 사람들은 이러한 관계를 받아들이기 어려울 수 있습니다. 여러분의 상황에서 이 도구의 이점이 단점보다 큰지 항상 직접 판단해야 합니다.

</div>

<div class="admonition recommendation" markdown>

![구글 로고](assets/img/data-broker-removals/google.svg){ align=right }

**나에 관한 결과**는 집 주소, 전화번호, 이메일 주소 같은 개인 연락처 정보가 구글 검색 결과에 나타나는지 확인하는 데 도움이 되는 무료 도구입니다. 개인 정보가 발견되면 삭제를 요청할 수 있습니다.

[:octicons-globe-16: 웹 도구 열기](https://myactivity.google.com/results-about-you){ .md-button .md-button--primary }
[:octicons-info-16:](https://support.google.com/websearch/answer/12719076){ .card-link title="문서" }

</div>

많은 경우 잠재적인 스토커나 가해자가 여러분의 개인 정보를 찾기 위해 가장 먼저 살펴보는 곳이 구글 검색이므로, 이 도구를 사용하는 것은 감수할 만한 절충일 수 있습니다. 하지만 이 도구는 발견된 웹사이트 자체에서 정보를 삭제하지는 않으며, 구글에 표시되는 목록만 삭제합니다. 발견된 결과에 대해서는 여전히 직접 옵트아웃하거나, 해당 사이트에서 직접 자동으로 옵트아웃해 주는 다른 서비스를 사용하는 것을 고려해야 합니다.

구글 계정에 모니터링할 주소, 전화번호, 이메일 주소를 각각 최대 3개까지 추가할 수 있습니다. 이 서비스는 일부 시장(처음에는 미국과 영국)에서 18세 이상 사용자만 이용할 수 있습니다.

결과가 발견되면 이 웹 도구에서 검토할 수 있습니다. 새 결과가 발견되면 계정의 지메일 주소로 이메일 알림을 받도록 선택할 수도 있습니다. 그러면 발견된 각 항목에서 **삭제 요청**을 클릭할 수 있으며, 구글이 요청을 검토합니다.

프라이버시 가이드의 테스트에서 이 도구는 구글 검색 결과에서 인물 검색 사이트를 안정적으로 삭제했지만, 개인 주소로 회사를 등록한 경우라도 _법인_ 등록 정보를 보여 주는 웹사이트에는 효과가 없었고, 소셜 미디어 프로필에도 효과가 없었습니다.

## 평가 기준 { #criteria }

**프라이버시 가이드는 추천하는 어떠한 프로젝트와도 제휴 관계가 없습니다.** [표준 평가 기준](about/criteria.md)에 더해, 객관적인 추천을 제공할 수 있도록 명확한 요구 사항을 마련했습니다. 데이터 삭제 서비스를 선택하기 전에 이 목록을 숙지하고, 직접 조사하여 자신에게 맞는 선택인지 확인하시기 바랍니다.

삭제 서비스 추천은 주로 위 섹션에서 언급한 제3자의 독립적인 전문 테스트, 프라이버시 가이드의 자체 내부 테스트, 커뮤니티의 리뷰를 종합한 결과를 바탕으로 합니다.

- 화이트 라벨 서비스이거나 다른 제공업체의 재판매업체여서는 안 됩니다.
- 데이터 브로커 업계와 제휴하거나 인물 검색 사이트에 광고를 구매해서는 안 됩니다.
- 여러분의 개인 데이터를 데이터 브로커 데이터베이스와 인물 검색 사이트에서 옵트아웃하는 목적으로만 사용해야 합니다.

[^1]: 스토커나 기타 위협으로 인해 당장 위험에 처해 _있다면_, 적어도 초기 "정리" 작업에는 [EasyOptOuts](#easyoptouts-paid) 같은 자동화된 도구를 적극적으로 고려해야 합니다. 나중에 상황이 좀 더 감당할 만해지면 수동 방식으로 돌아올 수 있습니다. 물론 위험한 상황이라면 스스로 해결하려 하기 전에 [경찰](https://onlineharassmentfieldmanual.pen.org/involving-law-enforcement)이나 다른 곳에 전문적인 도움을 요청하는 것을 항상 최우선으로 해야 합니다.
