**無障礙**是 [包容性](tip-keep-your-posts-and-community-inclusive.md) 不可或缺的一環，也應始終是我們志業中的優先事項。若要讓我們的隱私社群對所有人來說都充滿包容性，無障礙設計就不能只是事後才考慮的問題。我們必須從一開始就將其融入實踐之中。也就是說，必須確保我們所使用的語言、視覺元素、工具及場地，能讓盡可能多的人輕鬆使用。

以下是一些你我都能做到，對隱私議題、對社群發展改善都有所助益的事項：

## 人人皆應在各方各面享有無障礙

對於許多不需要任何特定無障礙措施的人來說，會以為無障礙只處理關&#x65BC;_&#x884C;動方&#x9762;_&#x7684;障礙，例如輪椅的使用環境。

雖然這確實是值得注重的因素，但在進行隱私相關工作時，我們還應留意許多其他類型的身心障礙，以及對應的合理調整。

思考一下對於推動我們的運動發展，以及促進隱私社群的多樣化而言，要如何讓每個人更輕鬆的接觸到我們所做的事。

在道德上，這也是理所當然的做法，理應化作常規、普及各界。

### 視覺、聽覺及其他感官方面的無障礙

無論何時，在倡議工作中使用圖片、音訊或其他感官元素，都應始終遵循最佳實踐方式（best practices），藉以確保您的內容讓視力、聽力或其他感官障礙者順利接觸和使用。

- [x] 如果您在網站或社群媒體貼文中使用圖片，請務必在每一次都加上適當的 [替代文字](https://abilitynet.org.uk/resources/digital-accessibility/five-golden-rules-compliant-alt-text)，以描述該圖片呈現的資訊。請留意你的讀者可能是使用 [螢幕閱讀器](https://en.wikipedia.org/wiki/Screen_reader)在瀏覽。

- [x] 在設計網站、海報、傳單或小誌時，請務必考量視障人士、弱視者、色盲者及其他視覺障礙者的 [視覺無障礙](https://webdesign.tutsplus.com/accessibility-basics-designing-for-visual-impairment--cms-27634a) 需求。

- [x] 請務必避免使用含有 [閃爍燈光](https://developer.mozilla.org/en-US/docs/Web/Accessibility/Guides/Seizure_disorders) 的設計與影片；若非得使用，則須顯示適當的警告訊息。閃爍或晃動的光線效果，甚至某些高對比度的靜態圖像，都可能引發光敏性癲癇患者的癲癇發作。

- [x] 若您在倡議活動中使用 [音訊素材](https://www.w3.org/WAI/people-use-web/abilities-barriers/auditory/)，請盡量在內容中加入字幕或文字紀錄，以便聽力障礙者能理解。若您籌辦一場有講者的大型活動，請試著聘請一名手語翻譯員。

- [x] 無論您是在製作內容或籌辦活動時，都請務必顧及感官障礙者或[感官敏感者](https://accessforallllc.com/sensory-and-cognitive-accessibility/)的需求。

### 網站設計方面的無障礙

若您在隱私權相關事務中開發網站，請務必遵循國際網路無障礙標準。

這一點非常重要，能確保使用輔助裝置的讀者能夠存取您的內容，也避免視障人士在存取您的內容時遇到困難。

- [x] 請熟悉全球資訊網協會（W3C）的 [國際網路標準](https://www.w3.org/WAI/standards-guidelines/)。這些標準已由「無障礙平台架構」（[APA](https://www.w3.org/WAI/about/groups/apawg/)）工作小組就無障礙支援方面進行了審查。

- [x] 請使用 [網頁無障礙評估工具](https://www.w3.org/WAI/test-evaluate/tools/list/) 來驗證您的網頁內容是否符合無障礙準則，或務必遵循 [網頁內容無障礙準則](https://www.pivotalaccessibility.com/2024/11/how-to-perform-a-web-accessibility-audit-step-by-step-guide/)（WCAG）。

- [x] 如果你的組織有足夠預算，建議聘請一位 [網頁無障礙顧問](https://accessibilityinnovations.com/blogs/web-accessibility-consultant/)。

### 全球與跨國方面的無障礙

無論您是用英文撰寫貼文、文章，還是整個網站，都請謹記：您的受眾很可能來自世界各地。

世界各地的人都能閱覽到你的英文內容，而其中許多人的母語並非英語。不要假設您的受眾僅來自你自己的國家或地區。順帶一提，這可是件好事！ ==如今，捍衛隱私權的戰役必定要是全球性的。==

- [x] 請注意，不要引用過多僅限於你所在國家或地區的參考資料。如果你非得這麼做，也請務必向其他地區的人說明這是什麼。

- [x] 在討論與政治相關的議題時，請務必說明政府機關是指什麼，並闡述你的國家有無任何特殊權利（不只寫名稱，要說明）。這樣一來，即使外界人士目前或許尚未直接受到此議題的影響，也能理解並支持你們的訴求。

- [x] 不要假設他人熟悉流行網路用語縮寫，例如 DIY（Do It Yourself，自己動手做）或 IIRC（If I Recall Correctly，如果我沒記錯的話）。對於非英語母語者來說，這些縮寫詞並不好懂。使用縮寫時，請務必至少在括號內註明一次完整表述；或者，更理想的做法是直接使用完整詞語。

- [x] 在邀請他人參加活動時，請考慮到有不同時區的人可能會讀到你的邀請函。若你的活動是在線舉辦，請務必在公告時間中註明 [時區](https://www.timeanddate.com/time/map/)。若您的活動是實體見面進行，請務必完整註明活動地點，包含國家與地區（[&#x8ACB;_&#x4E0D;&#x8981;_&#x50C5;列出城市名稱](https://www.roughmaps.com/destinations/20-places-around-the-world-that-share-the-same-name/22)）。

### 肢體方面的無障礙

在籌辦實體活動與聚會時，務必將各類行動不便者的通行需求納入考量。不僅包括場地周遭的無障礙設施，也涵蓋前往場地途中的。

- [x] 請確保您選擇的場地[適合輪椅使用者進出](https://sites.augsburg.edu/events/policies/accessible-events/accessible-event-planning-guide/)。若地點位於高樓層，請確認是否有電梯可供使用；如有需要，請確認是否設有無障礙坡道及自動門；並請確認門口及走廊的寬度是否足夠輪椅通行。

- [x] 請確保為您的賓客準備足夠且舒適的座位，並確保座位區及用餐區對使用輪椅或其他行動輔具的賓客而言皆容易使用。

- [x] 請確認附近是否有無障礙廁所。

- [x] 評估前往您所選場地時，各項大眾運輸選項的無障礙程度，包括專為使用輪椅或其他行動輔具人士設計的運輸服務。請發布一張有場地周邊大眾運輸站點的地圖。

- [x] 請仔細確認活動場地是否設有停車場及無障礙停車位。並將相關資訊與邀請函一併發布。

- [x] 請確認您選擇的場地是否適合視力或聽力障礙者使用。例如，請確認電梯上是否標有點字或凸起字體，並確保接待人員了解如何與聽障或重聽的賓客溝通。

### 醫療保健方面的無障礙

實體現場的無障礙不只關乎行動便利性。也關乎健康狀況各異的人們。包括容易感染傳染病的人士，或是因健康因素而需要其他特殊安排的人士。

- [x] 指定一名受過培訓的人員負責無障礙事宜，並預先將他的聯絡方式提供出來。這樣一來，若有人在活動前或活動中有任何疑問，便能聯絡到他。

- [x] 請鼓勵參與者佩戴口罩，並盡量選擇通風良好的場地，降低[呼吸道感染](https://health.clevelandclinic.org/superspreader-events)的風險。如果會提供餐點，請盡量選擇設有戶外用餐區的場地。

- [x] 請務必在活動現場準備幾盒 [防護口罩](https://health.clevelandclinic.org/do-masks-work)免費供來賓使用。如此一來，高風險族群者面對擁擠的人潮卻忘記自備口罩時，就有口罩能戴。

- [x] 請嘗試在活動場地內或附近規劃一處區域，讓參與者在活動期間若感到疲倦或過度刺激時，能夠在[安靜空間](https://eventwell.org/ensuring-inclusive-events-the-importance-of-supervising-quiet-spaces-for-neurodivergent-attendees-and-vulnerable-adults/)中舒適地休息。

- [x] 盡可能營造 [無香](https://www.chrc-ccdp.gc.ca/resources/publications/environmental-sensitivities-and-scent-free-policies) 環境，讓有氣味過敏、環境敏感或其他可能受氣味影響健康狀況的人也能對活動感到賓至如歸。

- [x] 培訓活動主辦方及志工，確保他們了解現有的無障礙設施，並能在回應詢問時提供實用的資訊。

### 飲食方面的無障礙

若您的活動提供正餐、點心或飲料，請務必提前做好充分準備，並避免來賓可能忌口的餐點。

- [x] 請清楚列出活動中將提供（或備有）哪些類型的食物和飲料。

- [x] 請提供聯絡資訊，以便民眾若有多項特殊飲食需求時，能預先聯絡相關人員。

- [x] 請盡量提供能滿足各種飲食需求的餐點與飲品，例如純素、無堅果、無麩質、無乳糖、無酒精或低糖等選項。

- [x] 若您主辦大型活動，請考慮在現場的急救包中備妥幾支 [腎上腺素自動注射器](https://greatergood.com/blogs/news/epinephrine-public-areas)，以防有人出現緊急的過敏反應。（譯註：在臺灣，法規將其列為處方藥品。請另尋求醫事人員建議參酌此項。）

- [x] 請確保賓客能取得免費且乾淨的飲用水，尤其是在活動安排於熱浪期間舉行時。

- [x] 請確保為可能需要哺乳的任何人提供一間安靜且有隱私的哺集乳室。

- [x] 請在發出邀請時一併提供上述所有資訊，以便賓客能妥善評估該活動是否適合他們參加。

### 安全方面的無障礙

安全性也是無障礙設計的一個重要面向。每個人面臨的威脅模式各異，且基於各種原因，部分人士在實際前往參與時，可能會有人身安全上的風險。

- [x] 為您的活動或社群實施一份 [行為準則](https://oshwa.org/resources/how-to-write-a-code-of-conduct/)。請確保設有明確的管道以舉報不當行為，並確保《行為準則》能妥善執行。

- [x] 請確認活動場地的洗手間安全無虞且照明充足。

- [x] 請確保您選擇的場地無論是搭乘大眾運輸工具或自駕前往都安全無虞，且若活動持續至深夜結束，請確認最近的停車場或公車站照明充足。

- [x] 如果您的活動場地位於夜間可能較為危險的區域，請考慮設立一項 [陪同服務](https://www.concordia.ca/campus-life/security/services/safe-walk.html)，例如由一群志工主動陪同賓客安全地步行至公車站。請預先公告這項資訊。

- [x] 請為您的活動制定明確的 [攝影規範](https://events.ccc.de/congress/2025/infos/privacy.html#photo-policy)，並嚴禁所有未經同意的拍攝行為。您也可以在賓客抵達時，為他們提供印有「禁止拍攝」或「拍攝 OK」的貼紙、徽章或掛帶配戴。這樣一來，若賓客不願在您的活動中被拍攝，便可明確表示不參與。如果您的活動聘請了官方攝影師，請務必確保他們謹慎行事，切勿拍攝到照片中出現佩戴這些徽章的人。理想情況下，應將活動照片的數量控制在最低限度，且在拍攝他人照片前，務必先徵得當事人的明確同意。

### 經濟方面的無障礙

無障礙議題中常被忽略的另一個面向，便是經濟上的無障礙。遺憾的是，許多人因經濟能力有限而無法參與某些活動，即使這些活動對於他們建立人脈與結識隱私權倡導同伴而言，都大有裨益。在籌辦活動時，請務必提供各種選項，以避免參與者遭到經濟能力上的排擠。

- [x] 請盡可能讓您的活動免費或部分免費，同時務必謹慎對待由 [資金贊助商](https://www.privacyguides.org/articles/2025/09/03/red-and-green-privacy-flags/#donations-event-sponsorships-and-other-revenues) 提供的資源與資金，以免與您的隱私價值觀產生衝突。

- [x] 為身心障礙程度較嚴重的人士預留一定數量的免費門票。

- [x] 為學生或失業的同儕提供折扣。

- [x] 創造兼職志工的機會，讓參與者可以提供一些協助，之後免費參加活動的其餘環節。

- [x] 請提供聯絡資訊，供有意申請免費或優惠服務，或希望與您討論其特殊情況的人士使用。

### 初學者方面的無障礙

[歡迎初學者](tip-welcome-beginners.md) 是我們所有事務當中至關重要的一環。要讓初學者也能輕鬆接觸您的內容跟活動，請務必留意語言使用、內容呈現方式，以及活動宣傳管道。

- [x] 務必在先用全稱或完整詞語解釋過後才用縮寫。

- [x] 使用術語或專有名詞時請謹慎，盡量意思明確並使用簡單的詞彙、運用易懂的比喻。

- [x] 謹防排擠。請多留意可能較沉默或尚未融入團體的新成員。[展現包容精神](tip-keep-your-posts-and-community-inclusive.md)，並邀請他們參與。

- [x] 請明確指出您的活動歡迎初學者參加。

- [x] 記得在潛在的參與者會觸及的地方宣傳您的活動。請注意，不要只邀請已在隱私議題相關社群之內的人，也要主動接觸尚不熟悉議題的群體。
