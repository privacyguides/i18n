구글 드라이브 같은 대부분의 온라인 **문서 협업** 플랫폼은 종단 간 암호화를 지원하지 않으므로, 클라우드 제공업체가 여러분이 하는 모든 작업에 접근할 수 있습니다. 제공업체의 개인정보 처리방침이 법적으로 여러분의 권리를 보호할 수는 있지만, 기술적인 접근 제한을 제공하지는 않습니다.

## 평가 기준 { #criteria }

**프라이버시 가이드는 추천하는 어떠한 프로젝트와도 제휴 관계가 없습니다.** [표준 평가 기준](about/criteria.md)에 더해, 객관적인 추천을 제공할 수 있도록 명확한 요구 사항을 마련했습니다. 프로젝트를 선택해 사용하기 전에 이 목록을 숙지하고, 직접 조사하여 자신에게 맞는 선택인지 확인하시기 바랍니다.

### 최소 요구 사항 { #minimum-requirements }

- 오픈 소스여야 합니다.
- E2EE로 인해 불가능한 경우가 아니라면 WebDAV를 통해 파일에 접근할 수 있어야 합니다.
- 리눅스, macOS, 윈도우용 동기화 클라이언트가 있어야 합니다.
- 문서 및 스프레드시트 편집을 지원해야 합니다.
- 실시간 문서 협업을 지원해야 합니다.
- 표준 문서 형식(예: ODF)으로 문서 내보내기를 지원해야 합니다.

### 우대 사항 { #best-case }

우대 사항은 이 카테고리에서 완벽한 프로젝트라면 갖추었으면 하는 사항을 나타냅니다. 추천 항목에 이 기능 중 일부 또는 전부가 없을 수도 있지만, 이러한 기능을 갖춘 항목은 이 페이지에서 다른 항목보다 높은 순위에 오를 수 있습니다.

- 파일을 일반적인 파일 시스템에 저장하는 것이 좋습니다.
- TOTP 또는 FIDO2 다중 인증이나 패스키 로그인을 지원하는 것이 좋습니다.
