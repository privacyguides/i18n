온라인 결제는 프라이버시에 있어 가장 큰 난제 중 하나입니다. 프라이버시를 지키며 효과적으로 결제하는 방법을 충분히 이해하고 있다면, 이 서비스는 판매자와 기타 추적자로부터 프라이버시를 보호하는 데 도움을 줄 수 있습니다. 무언가를 구매하기 전에 먼저 결제 개요 글을 읽어 볼 것을 강력히 권장합니다:

[프라이버시를 지키며 결제하기 :material-arrow-right-drop-circle:](advanced/payments.md ""){.md-button}

## 결제 마스킹 서비스 { #payment-masking-services }

<small>다음 위협으로부터 보호합니다:</small>

- [:material-account-search: 공개 노출](basics/common-threats.md#limiting-public-information ""){.pg-green}

대부분의 경우 실제 은행 정보나 청구 정보를 드러내지 않고 온라인 판매자에게 사용할 수 있는 "가상 직불카드"를 제공하는 서비스가 여러 있습니다. 이러한 금융 서비스는 익명이 **아니며**, "고객 확인(KYC)" 법의 적용을 받아 신분증이나 기타 신원 확인 정보를 요구할 수 있다는 점에 유의해야 합니다. 이러한 서비스는 주로 판매자의 데이터 유출, 마케팅 업체의 비교적 단순한 추적이나 구매 내역 연관, 온라인 데이터 도용으로부터 여러분을 보호하는 데 유용하며, 완전히 익명으로 구매하는 용도로는 적합하지 **않습니다**.

<div class="admonition tip" markdown>
<p class="admonition-title">현재 사용 중인 은행을 확인하세요</p>

많은 은행과 신용카드사는 자체적으로 가상 카드 기능을 제공합니다. 이미 이러한 옵션을 제공하는 곳을 이용하고 있다면, 대부분의 경우 아래 추천 서비스보다 그 기능을 사용하는 것이 좋습니다. 그래야 여러 주체에 개인 정보를 맡기지 않아도 됩니다.

</div>

### Privacy.com(미국) { #privacycom-us }

<div class="admonition recommendation" markdown>

![Privacy.com 로고](assets/img/financial-services/privacy_com.svg#only-light){ align=right }
![Privacy.com 로고](assets/img/financial-services/privacy_com-dark.svg#only-dark){ align=right }

**Privacy.com**의 무료 요금제에서는 매월 최대 12개의 가상 카드를 만들고, 카드별로 지출 한도를 설정하고, 카드를 즉시 정지할 수 있습니다. 유료 요금제에서는 매월 만들 수 있는 카드 수의 한도가 더 높습니다.

[:octicons-home-16: 홈페이지](https://privacy.com){ .md-button .md-button--primary }
[:octicons-eye-16:](https://privacy.com/privacy-policy){ .card-link title="개인정보 처리방침" }
[:octicons-info-16:](https://support.privacy.com){ .card-link title="문서"}

</details>

</div>

Privacy.com은 [기본적으로](https://support.privacy.com/hc/en-us/articles/360012407533-What-will-I-see-on-my-bank-statement-when-I-make-a-purchase-with-Privacy) 여러분이 구매한 판매자에 대한 정보를 은행에 제공합니다. "[비공개 지출 모드(private spend mode)](https://support.privacy.com/hc/en-us/articles/26732314558487-What-is-Private-Spend-Mode)" 기능을 사용하면 판매자 정보가 은행에 숨겨지므로, 은행은 Privacy.com으로 결제가 이루어졌다는 사실만 알 수 있고 그 돈이 어디에 사용되었는지는 알 수 없습니다. 하지만 이 기능이 완벽한 것은 아니며, 물론 Privacy.com은 여전히 여러분이 돈을 쓰는 판매자를 알고 있습니다.

### 평가 기준 { #criteria }

**프라이버시 가이드는 추천하는 어떠한 프로젝트와도 제휴 관계가 없습니다.** [표준 평가 기준](about/criteria.md)에 더해, 객관적인 추천을 제공할 수 있도록 명확한 요구 사항을 마련했습니다. 프로젝트를 선택해 사용하기 전에 이 목록을 숙지하고, 직접 조사하여 자신에게 맞는 선택인지 확인하시기 바랍니다.

- 판매자와 개인 금융 정보 사이에서 방패 역할을 하는 카드를 여러 개 만들 수 있어야 합니다.
- 카드 사용 시 판매자에게 정확한 청구지 주소 정보를 제공하도록 요구해서는 안 됩니다.

## 기프트 카드 마켓플레이스 { #gift-card-marketplaces }

<small>다음 위협으로부터 보호합니다:</small>

- [:material-eye-outline: 대규모 감시](basics/common-threats.md#mass-surveillance-programs ""){.pg-blue}

이 서비스를 사용하면 [암호화폐](cryptocurrency.md)로 다양한 온라인 판매자의 기프트 카드를 구매할 수 있습니다. 일부 서비스는 더 높은 한도를 위한 신원 확인 옵션을 제공하지만, 이메일 주소만으로 계정을 만드는 것도 허용합니다. 기본 계정의 한도는 일반적으로 하루 5,000~10,000달러부터 시작하며, (제공되는 경우) 신원이 확인된 계정은 한도가 훨씬 높습니다.

### 평가 기준 { #criteria_1 }

**프라이버시 가이드는 추천하는 어떠한 프로젝트와도 제휴 관계가 없습니다.** [표준 평가 기준](about/criteria.md)에 더해, 객관적인 추천을 제공할 수 있도록 명확한 요구 사항을 마련했습니다. 프로젝트를 선택해 사용하기 전에 이 목록을 숙지하고, 직접 조사하여 자신에게 맞는 선택인지 확인하시기 바랍니다.

- [추천 암호화폐](cryptocurrency.md)로 결제할 수 있어야 합니다.
- 신분증을 요구하지 않아야 합니다.

<div class="admonition tip" markdown>
<p class="admonition-title">중요 고지 사항</p>

이 내용은 법률 또는 금융 자문이 아닙니다. 프라이버시 가이드는 불법 행위를 지지하거나 장려하지 않으며, 기업의 서비스 이용 약관을 위반하는 어떠한 행위도 지지하거나 장려하지 않습니다. 이러한 추천이 여러분의 관할 지역에서 합법적이고 이용 가능한지 전문가에게 확인하세요. [모든 고지 사항 보기](about/notices.md).
