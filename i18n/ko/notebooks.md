### 크립티 { #cryptee }

<div class="admonition recommendation" markdown>

![크립티 로고](./assets/img/notebooks/cryptee.svg#only-light){ align=right }
![크립티 로고](./assets/img/notebooks/cryptee-dark.svg#only-dark){ align=right }

### Org-mode

<div class="admonition recommendation" markdown>

![Org-mode 로고](assets/img/notebooks/org-mode.svg){ align=right }

## 평가 기준 { #criteria }

**프라이버시 가이드는 추천하는 어떠한 프로젝트와도 제휴 관계가 없습니다.** [표준 평가 기준](about/criteria.md)에 더해, 객관적인 추천을 제공할 수 있도록 명확한 요구 사항을 마련했습니다. 프로젝트를 선택해 사용하기 전에 이 목록을 숙지하고, 직접 조사하여 자신에게 맞는 선택인지 확인하시기 바랍니다.

### 최소 요구 사항 { #minimum-requirements }

- 클라이언트는 오픈 소스여야 합니다.
- 모든 클라우드 동기화 기능은 E2EE로 보호되어야 합니다.
- 표준 형식으로 문서 내보내기를 지원해야 합니다.

### 우대 사항 { #best-case }

- 로컬 백업/동기화 기능은 암호화를 지원하는 것이 좋습니다.
- 클라우드 기반 플랫폼은 문서 공유를 지원하는 것이 좋습니다.
