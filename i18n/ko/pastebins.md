[**페이스트빈**](https://en.wikipedia.org/wiki/Pastebin)은 주로 대량의 코드를 편리하고 효율적으로 공유하는 데 사용되는 온라인 서비스입니다. 여기에 소개된 페이스트빈은 붙여넣은 콘텐츠에 클라이언트 측 암호화와 비밀번호 보호를 적용하며, 이 두 기능 덕분에 웹사이트나 서버 운영자는 붙여넣은 내용을 읽거나 접근할 수 없습니다.

## 프라이빗빈 { #privatebin }

<div class="admonition recommendation" markdown>

![프라이빗빈 로고](assets/img/pastebins/privatebin.svg){ align=right }

**프라이빗빈**은 여러분이 제출한 붙여넣기 데이터를 서버가 복호화하거나 읽을 수 없는 미니멀한 오픈 소스 온라인 페이스트빈입니다. 데이터는 브라우저에서 256비트 AES로 암호화/복호화됩니다. 제로빈(ZeroBin)을 개선한 버전입니다.

## 파스터 { #paaster }

<div class="admonition recommendation" markdown>

![파스터 로고](assets/img/pastebins/paaster.svg){ align=right }

**파스터**는 프라이버시와 단순함을 우선시하는 안전하고 사용하기 쉬운 페이스트빈 애플리케이션입니다. 종단 간 암호화와 붙여넣기 기록 기능을 갖추고 있어, 붙여넣은 코드를 기밀로 유지하면서도 언제든 접근할 수 있게 해 줍니다.

## 평가 기준 { #criteria }

**프라이버시 가이드는 추천하는 어떠한 프로젝트와도 제휴 관계가 없습니다.** [표준 평가 기준](about/criteria.md)에 더해, 객관적인 추천을 제공할 수 있도록 명확한 요구 사항을 마련했습니다. 프로젝트를 선택해 사용하기 전에 이 목록을 숙지하고, 직접 조사하여 자신에게 맞는 선택인지 확인하시기 바랍니다.

### 최소 요구 사항 { #minimum-requirements }

- 오픈 소스여야 합니다.
- 붙여넣은 데이터를 서버로 보내기 전에 클라이언트 측에서 암호화해야 합니다.
- 비밀번호로 보호된 파일을 지원해야 합니다.

### 우대 사항 { #best-case }

우대 사항은 이 카테고리에서 완벽한 프로젝트라면 갖추었으면 하는 사항을 나타냅니다. 추천 항목에 이 기능 중 일부 또는 전부가 없을 수도 있지만, 이러한 기능을 갖춘 항목은 이 페이지에서 다른 항목보다 높은 순위에 오를 수 있습니다.

- 평판이 좋은 독립적인 제3자의 감사 결과가 공개되어 있는 것이 좋습니다.
