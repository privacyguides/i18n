**뉴스 애그리게이터**는 온라인 신문, 블로그, 팟캐스트 및 기타 자료의 디지털 콘텐츠를 한곳에 모아 쉽게 볼 수 있게 해 주는 소프트웨어입니다. 뉴스 애그리게이터를 사용하면 좋아하는 콘텐츠의 소식을 놓치지 않고 받아 볼 수 있습니다.

## 평가 기준 { #criteria }

**프라이버시 가이드는 추천하는 어떠한 프로젝트와도 제휴 관계가 없습니다.** [표준 평가 기준](about/criteria.md)에 더해, 객관적인 추천을 제공할 수 있도록 명확한 요구 사항을 마련했습니다. 프로젝트를 선택해 사용하기 전에 이 목록을 숙지하고, 직접 조사하여 자신에게 맞는 선택인지 확인하시기 바랍니다.

- 오픈 소스 소프트웨어여야 합니다.
- 로컬에서 작동해야 합니다. 즉, 클라우드 서비스여서는 안 됩니다.

## 소셜 미디어 RSS 지원 { #social-media-rss-support }

잘 알려져 있지는 않지만, 일부 소셜 미디어 서비스도 RSS를 지원합니다.

### 레딧 { #reddit }

레딧에서는 RSS로 서브레딧을 구독할 수 있습니다.

<div class="admonition example" markdown>
<p class="admonition-title">예시</p>

`[SUBREDDIT]`를 구독하려는 서브레딧으로 바꾸세요.

```text
https://reddit.com/r/[SUBREDDIT]/new/.rss
```

</div>

### 유튜브 { #youtube }

유튜브 채널은 로그인하지 않고도 구독할 수 있으므로, 사용 정보가 구글 계정과 연결되지 않습니다.

<div class="admonition example" markdown>
<p class="admonition-title">예시</p>

RSS 클라이언트로 유튜브 채널을 구독하려면 먼저 해당 채널의 [채널 코드](https://support.google.com/youtube/answer/6180214)를 찾으세요. 채널 코드는 구독하려는 유튜브 채널의 확장된 설명(즉, "정보" 섹션)에서 찾을 수 있습니다: **정보** → **채널 공유** → **채널 ID 복사**. 아래의 `[CHANNEL ID]`를 바꾸세요:

```text
https://youtube.com/feeds/videos.xml?channel_id=[CHANNEL ID]
```

</div>
