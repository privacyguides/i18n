# 프라이버시 가이드 서비스

프라이버시 가이드는 기능을 시험하고 멋진 탈중앙화, 연합형, 오픈 소스 프로젝트를 홍보하기 위해 여러 웹 서비스를 운영하고 있습니다. 이 서비스 중 상당수는 일반에 공개되어 있으며, 자세한 내용은 아래와 같습니다.

- 소스: [github.com/discourse/discourse](https://github.com/discourse/discourse)

## 기티 { #gitea }

- 도메인: [code.privacyguides.dev](https://code.privacyguides.dev)

- 도메인: [matrix.privacyguides.org](https://matrix.privacyguides.org)
- 공개 범위: 초대 전용. 프라이버시 가이드 팀원, 매트릭스 모더레이터, 서드파티 매트릭스 커뮤니티 관리자, 매트릭스 봇 운영자, 그리고 안정적인 매트릭스 계정이 필요한 기타 개인은 요청 시 접근 권한을 받을 수 있습니다.
- 소스: [github.com/spantaleev/matrix-docker-ansible-deploy](https://github.com/spantaleev/matrix-docker-ansible-deploy)
