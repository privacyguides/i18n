프라이버시 가이드는 미국 영어로 작성되며, 확실하지 않을 때는 [APA 스타일 가이드라인](https://apastyle.apa.org/style-grammar-guidelines/grammar)을 참고해야 합니다.

일반적으로 [미국 연방 정부의 쉬운 언어 가이드라인](https://plainlanguage.gov/guidelines)은 명확하고 간결하게 글을 쓰는 방법에 대한 좋은 개요를 제공합니다. 아래에서는 이 가이드라인의 몇 가지 중요한 사항을 소개합니다.

## 독자를 위한 글쓰기 { #writing-for-our-audience }

프라이버시 가이드의 주요 [독자층](https://plainlanguage.gov/guidelines/audience)은 기술을 사용하는 성인입니다. 중학생에게 설명하듯이 내용을 지나치게 단순화하지 말되, 일반 컴퓨터 사용자에게 익숙하지 않은 개념에 관한 복잡한 용어를 남용해서도 안 됩니다.

### 사람들이 알고 싶어 하는 내용만 다루기 { #address-only-what-people-want-to-know }

사람들은 자신과 별 관련 없는 지나치게 복잡한 글을 필요로 하지 않습니다. 글을 쓸 때는 사람들이 무엇을 이루기를 원하는지 파악하고, 그에 필요한 세부 사항만 포함하세요.

> 독자에게 해당 자료가 왜 중요한지 알려 주세요. 예를 들어 “연구 보조금을 받고 싶다면 이렇게 해야 합니다.”처럼 말하세요. 또는 “연방 소유 석탄을 채굴하려면 다음 사항을 알아야 합니다.” 또는 “르완다 여행을 계획하고 있다면 이 글을 먼저 읽어 보세요.”

### 사람들에게 직접 말하기 { #address-people-directly }

우리는 다양한 사람들을 *위해* 글을 쓰지만, 실제로 글을 읽고 있는 사람*에게* 말하듯이 씁니다. "you"(여러분)를 사용해 독자에게 직접 말하세요.

> 다른 어떤 단일 기법보다도 “you”를 사용하는 것이 사용자를 정보 속으로 끌어들이고 정보를 자신과 관련된 것으로 느끼게 합니다.
> 
> “you”를 사용해 사용자에게 말하면 사용자는 자신의 책임이 무엇인지 더 잘 이해할 가능성이 높습니다.

출처: [plainlanguage.gov](https://plainlanguage.gov/guidelines/audience/address-the-user)

### "users" 사용 피하기 { #avoid-users }

사람들을 "users"(사용자)라고 부르지 말고, "people"(사람들)이나 글의 대상이 되는 집단을 더 구체적으로 설명하는 표현을 사용하세요.

## 콘텐츠 구성하기 { #organizing-content }

구성이 핵심입니다. 콘텐츠는 가장 중요한 정보부터 덜 중요한 정보 순으로 흘러가야 하며, 서로 다른 개념을 논리적으로 구분할 수 있도록 필요한 만큼 제목을 사용하세요.

- 문서의 섹션을 5~6개 정도로 제한하세요. 긴 문서는 여러 페이지로 나눠서 작성하는 편이 좋습니다.
- 중요한 개념은 **굵게**나 *기울임꼴*로 표시하세요.

출처: [plainlanguage.gov](https://plainlanguage.gov/guidelines/design)

### 주제문으로 시작하기 { #begin-with-a-topic-sentence }

> 무엇에 대해 읽게 될지 독자에게 미리 알려 주면, 독자가 문단을 다시 읽어야 할 가능성이 줄어듭니다. 제목도 도움이 되지만, 그것만으로는 충분하지 않습니다. 세부 사항을 제공하기 전에 독자에게 맥락을 제시하세요.
> 
> 우리는 흔히 생각하는 순서대로, 즉 전제를 먼저 제시하고 결론을 나중에 내리는 방식으로 글을 씁니다. 생각을 전개하는 과정으로서는 자연스러울 수 있지만, 이는 주제문이 문단의 끝에 위치하는 결과를 낳습니다. 주제문을 앞으로 옮겨 독자에게 글이 어디로 향하는지 알려 주세요. 요점에 도달하기 전에 독자가 많은 정보를 머릿속에 담고 있게 만들지 마세요.

출처: [plainlanguage.gov](https://plainlanguage.gov/guidelines/organize/have-a-topic-sentence)

## 단어를 신중하게 선택하기 { #choose-your-words-carefully }

> 단어는 중요합니다. 단어는 글과 말을 통한 소통의 가장 기본적인 구성 요소입니다. 사람들이 이해하지 못할 전문 용어, 기술 용어, 약어를 사용하여 내용을 복잡하게 만들지 마세요.

가능하면 약어를 피하려고 노력해야 하지만, 기술 분야에는 약어가 넘쳐납니다. 일반적으로 약어/두문자어는 페이지에서 처음 사용할 때 풀어서 쓰고, 반복해서 사용된다면 약어 용어집 파일에 추가하세요.

> 캐시 맥긴티는 간단하고 직접적인 문장을 장황하게 부풀리는 방법을 농담조로 소개합니다:
> 
> > 다양하게 이용 가능하고 적용 가능한 여러 연구들이 사실상 그 자체로, 추가적이고 적절한 야간 고용이 평일 자정 이전 및/또는 주말 오전 2시 이전을 포함하되 이에 국한되지 않는 야간 시간대에 청소년기의 미성년자들을 도로에서 대체로 멀어지게 할 수 있다는 사실을 일반적으로 확인했다는 점에 주목하는 것이 매우 중요하다고 여겨진다는 사실은 피할 수 없습니다.
> 
> 그리고 더 강력하고 간단한 단어를 사용한 원래 문장은 다음과 같습니다:
> 
> > 야간 일자리가 늘어나면 청소년들이 거리에 나오지 않을 것이다.

## 간결하게 쓰기 { #be-concise }

> 불필요한 단어는 독자의 시간을 낭비합니다. 훌륭한 글쓰기는 대화와 같습니다. 독자가 알 필요 없는 정보는 생략하세요. 해당 분야의 전문가라면 이것이 어려울 수 있으므로, 다른 사람에게 독자의 관점에서 정보를 살펴봐 달라고 하는 것이 중요합니다.

출처: [plainlanguage.gov](https://plainlanguage.gov/guidelines/concise)

## 대화하듯이 쓰기 { #keep-text-conversational }

> 동사는 글쓰기의 연료입니다. 동사는 문장에 힘과 방향을 부여합니다. 동사는 글에 생기를 불어넣고 더 흥미롭게 만듭니다.
> 
> 동사는 청중에게 무엇을 해야 하는지 알려줍니다. 누가 무엇을 하는지 명확히 하세요.

### 능동태 사용하기 { #use-active-voice }

> 능동태를 사용하면 누가 무엇을 해야 하는지 명확해집니다. 책임 소재에 대한 모호함을 없애 줍니다. “It must be done”(그것은 이루어져야 한다)이 아니라 “You must do it”(여러분이 그것을 해야 한다)이라고 쓰세요.

출처: [plainlanguage.gov](https://plainlanguage.gov/guidelines/conversational/use-active-voice)

### 요구 사항에는 "must" 사용하기 { #use-must-for-requirements }

> - 의무에는 “must”
> - 금지에는 “must not”
> - 재량에 따른 행동에는 “may”
> - 권장 사항에는 “should”
